# Genesis

1. Read `AGENTS.md`, `genesis.yaml` and `docs/WORK.md`.
2. Identify which contracts the requested outcome can materially affect.
3. Load only those contracts.
4. If the active outcome is empty, write a concise outcome, scope, non-goals and required evidence before implementation.
5. Execute the work rather than expanding process.
6. Stop for explicit approval only at a decision gate defined by `AGENTS.md`.
7. Verify the required evidence.
8. Synchronize affected contracts with reality.
9. Record durable rationale in `DECISIONS.md` only when future agents would otherwise rediscover it.
10. Finish with result, evidence, changed contracts and remaining risk.

Genesis should reduce coordination cost. If following the framework creates work that does not protect a decision, risk or future handoff, simplify.
