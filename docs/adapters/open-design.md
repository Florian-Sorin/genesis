# Adapter — Open Design

Open Design is a recommended current design workshop, not a Genesis dependency.

## Input

Provide only the context needed for the design problem:

- relevant `PRODUCT.md` rules and flow;
- `DESIGN.md`;
- the active outcome and constraints from `WORK.md`;
- existing UI references when continuity matters.

## Exploration

Use the workshop for composition, alternatives, visual direction, states and interaction exploration.

Do not let the workshop silently redefine product behaviour.

## Handoff back to Git

Preserve only what implementation needs:

- approved visual reference when useful;
- important state and interaction decisions;
- assets;
- deviations from the current DESIGN contract;
- implementation constraints.

If the workshop changes a major visual direction or primary flow, cross the corresponding Genesis decision gate before treating it as approved.

If Open Design is unavailable or replaced, the same contract can be used with another workshop.
