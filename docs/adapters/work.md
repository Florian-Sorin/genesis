# Adapter — ChatGPT Work

Use Work when the task benefits from broad research, synthesis, connected sources, multi-step orchestration or producing/updating project artifacts.

## Recommended handoff into Genesis

Work should leave the repository with decisions, not conversation history.

Useful outputs are:

- evidence that changes `PROJECT.md`;
- clarified product rules for `PRODUCT.md`;
- researched constraints or alternatives that support a decision;
- a proposed active outcome in `WORK.md`;
- durable rationale in `DECISIONS.md` when a decision is approved.

## Boundary

Work is not required to build a Genesis project. Another orchestrator or a capable coding agent can perform the same role.

Do not make a core rule depend on Work-only features.
