# /journal

Ajoute une entrée dans `docs/JOURNAL.md` pour capitaliser un apprentissage de session.

## Instructions

1. Lire `docs/JOURNAL.md` pour comprendre le format en place.
2. Demander à l'utilisateur (ou déduire du contexte de la session) :
   - **Contexte** : 1 ligne (story concernée, sujet abordé).
   - **Ce que j'ai appris** : 1-3 lignes, factuel, sans paraphrase.
   - **À éviter / à refaire** : optionnel, 1-2 lignes.

3. Évaluer si l'apprentissage est :
   - **Durable** (vrai au-delà de cette story) → proposer de l'ajouter en "Apprentissages durables (pinned)" en plus de l'entrée de session.
   - **Ponctuel** → entrée de session uniquement.

4. Filtrer le bruit : si l'apprentissage est trivial ou évident, **proposer de ne rien écrire**. Le journal vaut par sa concision.

5. Ajouter l'entrée en haut de la section "Entrées de session" (plus récent en haut), format :

   ```
   ### YYYY-MM-DD — ST-XXX — [titre court]

   **Contexte :** ...
   **Ce que j'ai appris :** ...
   **À éviter / à refaire :** ...
   ```

6. Si c'est un apprentissage durable, ajouter aussi une bullet dans "Apprentissages durables (pinned)".
